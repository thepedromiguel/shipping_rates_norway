# Shipping Rates Norway

This is a projected undertaken in Excel where unorganised data from different sheets was cleansed and transformed into a neat structure depicting shipping rates from global ports to Norway, incorporating data such as equipment type, origin and destination port, freight forwarder, reference, currency, volume and date ranges.
